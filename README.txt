CHRIST REVEALED YOUTH MINISTRIES (CRYM) — STARTER APP

WHAT THIS IS
A starter Progressive Web App (PWA) for phones and computers. It includes sample pages for Home, Bible, Devotions, Sermons, Programs and About CRYM. It is designed to support offline caching when hosted over HTTPS or tested in a suitable local development server.

IMPORTANT LIMITATIONS
- This is a front-end starter/demo, not a finished production app.
- It does not yet have secure administrator/approved-leader accounts, a database, or online content publishing.
- Do not put private information or real prayer requests into this demo.
- The NIV tab is a placeholder. Add NIV text only through an authorized/licensed source or API. The sample John 14:6 text is KJV.
- Offline functionality depends on browser support and serving the app through HTTPS or localhost.
- To create a conventional Android APK, the project must be wrapped/built using an Android packaging workflow. This ZIP itself is not an APK.

HOW TO PREVIEW
1. Extract this ZIP on a computer.
2. Open index.html to inspect the design (some offline/PWA features may not work from a file:// address).
3. For full PWA testing, host the files on an HTTPS static host or run a local web server.
4. Your supplied CRYM logo is included as crym-logo.jpg and shown in the header. The visual style can be adjusted further.
